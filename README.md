# Text Preprocessor using Python and NLTK

A beginner-friendly Natural Language Processing (NLP) mini-project that cleans and preprocesses text using Python and NLTK.

## Features

- Converts text to lowercase
- Tokenizes text into individual tokens
- Removes English stopwords
- Removes punctuation
- Displays original and cleaned token counts
- Accepts text through user input

## Technologies Used

- Python
- NLTK

## How It Works

The program takes text from the user and performs the following preprocessing steps:

1. Converts the text to lowercase
2. Tokenizes the text
3. Removes stopwords
4. Removes punctuation
5. Returns the cleaned tokens

## Example

### Input

```text
I love learning Artificial Intelligence and Natural Language Processing!

### Example Output

```text
Original tokens: 10
Cleaned words: 7
Removed tokens: 3
Cleaned text: ['love', 'learning', 'artificial', 'intelligence', 'natural', 'language', 'processing']
```
